# Home and library UI integration into main

- Home: device-local greeting with Edwyn, 24 latest albums, 12 recently opened albums, eight artist entries, and bounded recommendations from the existing library. No individual track shelf or redundant shortcut buttons.
- Cover flow: visible reflected covers, smooth scroll-linked transforms, continuous touch momentum, desktop mouse dragging with velocity projection and click suppression after a drag. New Release uses a gentler spotlight and caption crossfade.
- Library: nine broad Genre groups without modifying imported tags. Familiar Chinese/Asian artists sort first, then local plays/favorites/library size, with A–Z retained. This is an editorial familiarity tier, not a live chart.
- Player: full-screen cover opens its album; artist names open the artist discography. Navigation follows track changes. Lock-screen previous/next handlers tolerate unsupported Media Session actions.
- Cards: album titles sit directly above artist/year metadata; badges do not stretch the title row. Mobile artist and Albums grids retain 16px row spacing.
- Tracks: ignore superseded requests so older search responses cannot replace newer results.
